# Документация проекта DairyHub

**DairyHub** — цифровая платформа управления торговой командой молочной компании (Республика Казахстан, валюта — тенге ₸). Платформа объединяет данные представителей, склада и бухгалтерии и превращает каждое отклонение в продажах в задачу для подразделения, которое может его устранить: **отклонение → анализ → причина → задача ответственному → контроль**.

## Ключевые параметры одним взглядом

| Параметр | Значение |
|---|---|
| Роли | Торговый представитель, Руководитель/супервайзер, Склад, Бухгалтерия, Администратор |
| Геозона визита | 150 м (вне — визит разрешён с флагом и комментарием); точность GPS хуже 100 м — предупреждение |
| Короткий визит | < 5 мин |
| Пропущенный визит | Нет check-in к 19:00; сигнал по представителю при ≥ 3 пропусках за 7 дней |
| Напоминания об отчёте | Через 30 мин после check-out; итоговое в 18:00 |
| Падение продаж | 7 дней vs среднее 4 предыдущих недель, ≥ 30% (SKU — при базе ≥ 14 ед./нед.; уровень представителя — по незамороженной продукции) |
| Контроль результата | 14 дней |
| SLA задач | Склад 24 ч; Бухгалтерия 48 ч; Руководитель 48 ч; Представитель — до следующего визита |
| План | Среднее за 3 мес × сезонность × потенциал (A 1,10 / B 1,00 / C 0,95); скорректированное выполнение — без извинительных потерь |
| Уровни премирования | 80% / 100% / 120% (суммы задаёт компания) |
| Морозильник | Норма ≤ −18 °C; > −15 °C дольше 2 ч — задача руководителю + представителю |
| Морозильник без продаж | 0 продаж 3 дня — уведомление; программа из 4 этапов; через ≥ 56 дней при выручке мороженого за 30 дней < 120 000 ₸ — оценка перемещения |
| Доступ | Пароль ≥ 8 символов (буквы и цифры); 5 ошибок — блокировка 15 мин; сессия 12 ч / 30 дней |
| Срок проекта | 6 месяцев |
| Бюджет | 30 млн ₸ (25 млн ₸ + резерв 5 млн ₸), предварительная модель |
| Хранение ПДн | На территории РК (Закон РК «О персональных данных и их защите») |

## Статус документов

Версия 1.0 — черновик для согласования на этапе М1. Все целевые значения KPI и предварительные параметры (веса оценки перемещения, калибровка уверенности гипотез, распределение бюджета направления «Морозильник без продаж») подлежат уточнению на М1 и калибровке на пилоте (М5).

Диаграммы выполнены в формате Mermaid и отображаются в GitHub, GitLab и большинстве Markdown-редакторов.
