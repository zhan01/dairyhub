# DairyHub

Единая цифровая платформа управления торговой командой молочной компании: мобильный сайт торгового представителя, веб-панель руководителя, склад и бухгалтерия в одной системе. DairyHub находит отклонения, анализирует возможные причины и направляет задачу ответственному подразделению.

**Демо:** https://zhan01.github.io/dairyhub/
Демо-аккаунты (пароль `DairyHub2026`): `manager@`, `rep@`, `warehouse@`, `accounting@`, `admin@demo.dairyhub.kz` — или кнопки быстрого входа на странице входа.

## Демо-реализация

Публичное демо — статическое SPA на GitHub Pages. Слой данных — браузерный адаптер (IndexedDB/localStorage) с теми же контрактами, что и целевой REST API: пароли хешируются PBKDF2-SHA256, сессии с истечением, блокировка после 5 неудачных попыток. Каждый посетитель получает изолированное пространство с демо-данными в своём браузере. Целевая архитектура (NestJS, PostgreSQL/PostGIS, TimescaleDB, Redis, MQTT, Keycloak, хостинг в РК) описана в [`docs/04-architecture.md`](docs/04-architecture.md).

## Покрытие ТЗ

Реализовано в демо: FR-001…FR-019 (включая GPS-трек рабочей смены, офлайн-режим через service worker, редактирование графика визитов), FR-030…FR-038, FR-040…FR-043 (вложения, уведомления о просрочке SLA, отклонение гипотезы исполнителем), FR-050…FR-054 (утверждение и корректировка плана), FR-060…FR-074, FR-080…FR-085 (уведомления в приложении и системные уведомления браузера, экспорт в Excel, справочники), FR-090…FR-097.

Требуют серверной части (промышленная версия): каналы Telegram и SMS, фоновый GPS-трекинг при заблокированном экране (нужно нативное приложение), общая база данных между устройствами, интеграция с 1С и приём телеметрии датчиков по MQTT.
